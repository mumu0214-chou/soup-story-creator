# 汤底四宫格示例

以下是完整提示词的写法示例，保留了已有创作中的两种主题。两份均按无附图也能理解的方式书写；实际任务有参考图时，先查看并写明其角色，再依据参考调整。它们是创作方案，不证明某张原图的配方，也不要求所有汤都使用同一锅、同一碗或四行文案。

## 菌菇清汤

创作设定：香菇、金针菇、白玉菇、姜片；成品清透淡金色；纯汤底制作，不加牛肉产品。若用户另给材料，应随之修改所有阶段。

```text
生成一张竖版 2×2 四宫格菌菇清汤制作图，图片和中文步骤一次生成。四格从左到右、从上到下展示同一次做汤，紧密拼接，无宽白边。自然家庭厨房手机近拍，普通室内光，真实金属反光和食物细节；食材、锅及汤碗占各格主要面积，不做菜单式图标或商业海报。

四格使用相同的香菇、去根金针菇、白玉菇和姜片；烹饪两格保持同一口银色双耳不锈钢锅及同一厨房环境。食材在煮制中自然变软，不突然换种类或切法。只展示这份菌菇清汤，不出现牛肉、肉卷、肉丸或海鲜。

左上：近距离略俯拍不锈钢备料盘，洗净的香菇部分对半切，金针菇整理成小束，白玉菇和姜片分放；食材清楚，台面只露少量。
右上：上述材料已入同一口银色双耳锅，清水开始冒细小气泡，三种菌菇各自可辨，少量蒸汽；尚未煮成浓色汤。
左下：同一锅煮开后小火煮至菌菇熟透，食材变软，汤呈清透淡金色，有自然气泡和薄蒸汽，三种菌菇仍可辨；不要变成乳白浓汤或红汤。
右下：日常白底蓝边瓷碗盛同一锅淡金色清汤，白瓷汤匙舀起一勺，勺中以清汤为主，碗里留少量相同菌菇，近拍突出清亮汤色。

四格中央交界附近依序排下列四行简体中文，浅黄色粗体、黑色描边、轻微倾斜，适度大小且不挡住各格关键食材。逐字准确，只写以下文字：
「菌菇洗净，整理好备用」
「加入清水和姜片，一起煮开」
「转小火煮至菌菇熟透，调味」
「先喝一碗菌菇清汤，再开始涮菜」
```

## 贵州番茄酸汤：使用成品红酸汤料的版本

创作设定：新鲜番茄、姜、蒜与成品贵州红酸汤料，按汤料说明调节用量与烹煮要求；重点展示材料入锅到酸汤完成，不声称示范了红酸汤料的发酵制作。用户要求自制发酵版本时，重新取得可靠配方与过程。

```text
生成一张竖版 2×2 四宫格贵州番茄酸汤制作图，中文步骤与画面一次生成。四格紧密无宽白边，从左到右、从上到下阅读。家庭厨房手机近拍、普通室内光，真实不锈钢反光、番茄质感与蒸汽；食材和器物占满各格主要区域，环境朴素自然。

这是使用成品贵州红酸汤料的家庭做法。四格属于同一次制作，烹饪两格使用同一口银色双耳不锈钢锅；相同番茄块、姜片和蒜瓣从备料到煮汤连续出现，成品为红橙色番茄酸汤。不加入牛肉产品、丸子、菌菇或参考图里的其他食材。

左上：不锈钢备料盘中放洗净番茄、已切番茄块、姜片和蒜瓣，旁边小碗盛红橙色贵州红酸汤料；材料可辨，少量厨房台面入画。
右上：番茄块、姜片和蒜瓣已加入银色双耳锅中的清水，番茄开始变软，有细小气泡与轻微蒸汽；此时尚未加入红酸汤料，汤呈较淡的番茄色。
左下：同一锅已经加入备料小碗中的红酸汤料并煮开，形成红橙色酸汤，保留自然软化的番茄块；气泡与薄蒸汽可见，汤色比上一格明显加深，油花适度。
右下：白底青花边汤碗盛同一锅红橙色酸汤，白瓷汤匙舀起一勺，碗里少许番茄块，汤色和质感与左下完成态一致。

在四格交界附近依序排四行简体中文，浅黄色粗字、黑色描边，轻微倾斜，清晰完整，不挡住主要材料。逐字写为：
「番茄洗净切块，姜蒜备好」
「番茄加水煮软」
「加入贵州红酸汤料煮开」
「酸汤煮好，准备涮菜」
```

## 联用请求如何计数

请求：“用我的牛肉产品图做两张家庭火锅餐桌图，汤底统一为贵州番茄酸汤，再做一张对应的四宫格制作图，所有文字一起生成。”

建立同一份汤底设定，制作 B01、B02 两张餐桌图及 S01 一张四宫格，共三张成图。牛肉产品只按餐桌图的需要附入；汤图不自动展示牛肉。每张提示词包含它自己的全部文字，每张初次生成仅一次调用；不要套用默认十张，也不要把一张四宫格计为四张独立成图。
